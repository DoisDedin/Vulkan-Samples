= Transform Sequence 05

Visualises the algebra exercises:  
* the white triangle shows the original points A, B, C.  
* the cyan triangle applies a 180° rotation around X.  
* the orange triangle applies the “rotate → translate → scale” chain discussed in class.  

Push constants carry the individual model matrices while a single uniform buffer provides the shared view-projection.
